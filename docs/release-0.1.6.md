# DeepWorker 0.1.6（已发布）

> 本版已发布到 npm / GitHub Release。

## 一、功能变更

### 1. 轮次操作与图片

- 编辑重发归档原对话补 `stopActivity: true`；设置关闭/接口缺失/失败都会明确提示。

- 工作区未提交改动接入原生右侧栏：文件树 tab 点「工作区改动」打开；按 tab 所属会话取 cwd；不是本轮改动，不写 git。

- 从本轮「在此分支」创建的子会话，标题追加「· 分支」，头部显示「来自第 N 轮」；点击回到父会话并滚到原轮。


- 重试、编辑重发保留原消息的图片和文件附件。
- 已结束轮次改为消息下方的行内编辑器：
  - 取消：不 fork，不改原消息。
  - 发送：才 fork 到本轮之前。
  - 原图可删除。
  - 本地图片可添加、粘贴、拖放。
- 运行中的最新轮没有 `turnTail` 时，右键编辑会：
  - 停止当前轮。
  - 把原文回填输入框。
  - 通过输入框的拖放管线恢复原图草稿。
  - 不自动重发，等用户发送。

### 2. 随手百科

- 设置页新增独立「随手百科」tab；可分别关闭「存入笔记」「生成新会话」。
- 接口/模型下拉读取 DSH 原生 provider/model；不保存 API key 或 endpoint。

- 设置 → 功能引入 / 移除新增真实总开关；关闭后右键入口消失。

- 选中文字右键「随手百科」。
- 选区旁气泡显示加载、答案、错误。
- 宿主新增无状态接口：

```text
POST /dsh-deepworker/quick-explain
{ "text": "选中内容", "question": "请解释这段内容。" }
```

- 只调用一次默认模型；不创建、不读取会话；不写会话日志。
- 固定短答 system prompt；客户端 60 秒超时。
- 气泡按钮：
  - 存入笔记：`Q：...` + 空行 + `A：...`，标签「随手百科」。
  - 生成新会话：新建空白会话，把 Q&A 和「我的指令：」预填到输入框；不立即调用模型。
- 本地缓存按 provider/model + 选中文字 + 问题区分，30 天、最多 100 条；跟随默认模型时默认模型切换会失效旧缓存；命中不调模型，显示「来自本地缓存」，可「重新查询」。
- 关闭气泡或重新查询会中止尚未完成的模型请求；点击外部或 Esc 可关闭气泡。
- 存入笔记时记录来源 session/turn；笔记卡片显示「来源：第 N 轮」，点击回跳；目标会话未加载完时短暂重试。
- 笔记页新增「复制 Markdown」，包含时间、标签、来源；标题/标签/来源按当前语言输出。
- 随手百科 Q&A 笔记的 Q/A 标记按当前语言输出。
- 随手百科独立于「引用」开关。

### 3. 快捷短语

- 设置新增真实总开关；关闭后下拉与快捷键不注册。

- 输入框右侧「短语」下拉。
- 点击短语插入光标位置，插入后光标落到末尾。
- `+` 新增一条内容输入框。
- Enter 保存；Shift+Enter 换行；Esc 取消。
- `×` 删除已有短语，或取消新增。
- 本地 localStorage 保存，最多 20 条，无名称字段；重复内容和超过 20 条会提示；点击外部或 Esc 关闭下拉。
- 快捷键 `⌘/Ctrl+Shift+P` 打开短语；`↑/↓` 选择，`Enter` 插入，`Esc` 关闭；可在 DSH 快捷键面板改键。

### 4. 命令状态

- 会话头部命令按钮显示状态点：
  - 绿：命令仍在运行
  - 灰：未运行 / 已结束 / 已停止
  - 红：失败
- 同一动作运行中再次点击会提示，不重复启动。
- 命令按钮页新增「执行气泡提示」开关；关闭后静默例行启动/结束，错误和拒绝仍显示。
- 命令按钮页新增状态图例：绿=运行中、灰=未运行/已结束/已停止、红=失败。
- 状态按每个按钮自己的命令进程判断：运行中绿、进程结束灰、失败红；不假设启动/停止成对，也不互相清灯。
- 停止后旧执行流的 “Terminal no longer exists” 不再覆盖为红色失败，统一归为已停止。
- 运行中不提供停止按钮；状态点只显示状态，不承担按钮职责。

### 5. 设置界面与菜单

- 设置页统一字号、行高、字重、颜色和间距。
- 设置行不再画无意义横线；只在功能边界和表格保留分隔线。
- 用户消息右键只保留消息级动作；分支只在助手轮末。
- 无选区时不显示引用、笔记、随手百科。
- 「编辑重发」排在官方复制/时间按钮之前，不再 fixed 浮动。

## 四、已知边界

- 随手百科依赖默认模型选择；没有默认模型时返回错误。
- 随手百科不建会话，因此不会出现在会话历史里；需要继续追问时用「生成新会话」。
- 宿主路由只接受本机回环请求，限制请求体 24 KiB、选中文字 6000 字符、问题 1000 字符。
- 行内编辑器的图片添加使用 base64；没有上传进度/失败重试 UI。
- 命令状态是本进程内状态，刷新/重启后不保留。
- 文件编辑/保存不做：只复用原生 diff/预览；编辑交给外部 IDE。
- 0.1.6 已发布；README 安装命令已改为 0.1.6。
